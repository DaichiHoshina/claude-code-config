# 手順案内は新規構築と運用中環境を区別する

セットアップ手順を作成する前に、相手の環境が新規か運用中かを見極める。運用中の環境へ初期構築手順をそのまま提示すると、user の資産を消す。

## Why

2026-08-11 に実害が出た。onecomme-tools の movie-trigger で「もっと最初から」と求められ、テンプレート folder の `cp -r` を含む新規セットアップ手順を出した。user が運用中の folder を置き直した結果、`movies/` の動画資産が消えた。repo 管理外で復元できないものを含んでいた。

手順そのものは正しかった。実行 context が運用中だったために破壊操作へ変わった。

## How to apply

- 手順を作成する前に、相手の環境が新規か運用中かを確かめる (会話履歴から自明なら質問しない)
- 運用中なら、repo 管理外の user 資産が置かれる dir を先に特定する (`uploads/` / `movies/` / `config/` 等)
- その dir を扱う工程には、既存資産を一時的に別の場所へ移動する手順を必ず前置する
- 「最初から」と求められても、構築済み前提の差分手順へ組み替えて返す
- README 等の恒久 doc には「既存環境へ入れ直す場合」の注意節を最初から置く
