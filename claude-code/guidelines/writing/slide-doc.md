# スライド・プレゼン資料 (Marp / PowerPoint / Google Slides / Keynote)

共通原則は [PRINCIPLES.md](PRINCIPLES.md)、論理構造は [long-form-doc.md](long-form-doc.md) の [文書構造論 — PREP 以外の選択肢](long-form-doc.md#文書構造論--prep-以外の選択肢)（ピラミッド原則）を参照する。この file はスライド固有の規範のみ扱う。

> **原則**: スライドは読む文書ではなく、主張を 1 枚ずつ渡す道具。文書として完結させたい内容は長文 doc に書き、スライドは判断と行動を促す骨子に限定する。

## 1 スライド 1 メッセージ

- 各スライドの主張を 1 文 (メッセージライン) で書けるかを先に確かめる。書けないスライドは分割するか削る
- メッセージラインはタイトル位置に**文で**記載する (体言止めの見出し「売上の推移」でなく主張「売上は 3 期連続で伸びている」)。本文はその根拠だけを記載する
- スライド一覧 (サマリービュー) でメッセージラインだけを通読して、話の流れが成立するかを確認する。これが構造ゲート (PRINCIPLES.md「文書全体の読みやすさ」) のスライド版になる
- この形式は assertion-evidence (文の主張見出し + 図で示す根拠) として研究の裏付けがある。句の見出し + 箇条書きの伝統形式より理解・記憶が良く、聴き手の認知負荷も低い (Alley, Penn State の学生実験)。本文は箇条書きを図解 + 図に近接した短文へ置き換えられないか先に検討する

## 構成 (ピラミッド原則の適用)

- 冒頭 1-3 枚で結論と全体像を渡す (結論 → 根拠の順。長文 doc の conclusion-first と同じ)
- 1 枚目の結論を支える根拠スライドを Why 軸で並べ、根拠の詳細は appendix へ送る
- 発表時間から枚数を逆算する (1 枚 1-2 分目安)。収まらない分は本編でなく appendix に置く

## 図解の選択

数値や関係は文章より図表で渡す。型の選択を誤ると誤読の原因になるため、下表から採用する。

| 伝えたいこと | 型 |
|---|---|
| 項目間の比較 | 縦棒グラフ / 表 |
| 時系列の推移 | 折れ線グラフ |
| 構成比 | 積み上げ棒 (円グラフは 3 区分以内のみ) |
| 相関 | 散布図 |
| 流れ・依存 | フロー図 / シーケンス図 |
| 構造・包含 | ツリー / ブロック図 |

- グラフには「何を読み取ってほしいか」の注釈 (強調色 / 矢印 / 1 文) を必ず添える。データを置くだけで読み手に解釈させない
- 数値には出典と計測条件 (link / query / 期間) を添える

## 認知負荷を下げる 3 原則 (Mayer)

マルチメディア学習研究 (Richard Mayer) のうち、スライドに直結する 3 原則を適用する。

- **無関係要素の排除 (coherence)**: 主張に寄与しない飾り・画像・BGM を削る。書くより削る方が理解が深まる (23/23 実験で支持、効果量中央値 0.86)
- **強調の合図 (signaling)**: 読み取ってほしい箇所へ矢印・強調色・1 文注釈で合図を置く (「グラフに注釈を必ず添える」の根拠)
- **重複の排除 (redundancy)**: 口頭で話す文と同じ文章をスライドに書かない。図 + 口頭説明が最も伝わり、同文の読み上げ併記は負荷を上げる (「発表原稿をスライドに書かない」の根拠)

## デザイン 4 原則

装飾は最小にし、4 原則だけ守る。

- **近接**: 関連する要素を近づけ、無関係な要素を離す
- **整列**: 全要素を grid に合わせる。中央揃えと左揃えを 1 枚の中で併用しない
- **反復**: 色 / フォント / レイアウトの規則を全スライドで統一する
- **コントラスト**: 強調は 1 枚につき 1 箇所。全部を強調しない

色は base + 強調 1 色 + 無彩色に限定する。強調色を増やすほど強調は死ぬ。

## テキスト規律

- 箇条書きは 1 枚 5 行以内・1 行 1 主張。超えるなら分割か図解化
- スライド上の文は plain JP (`guidelines/writing/PRINCIPLES.md`)。メッセージラインは文、箇条書き項目は名詞句でも文でもよいが 1 枚の中で合わせる
- 発表原稿をスライドに書かない。話す内容は speaker note へ、配布用の補足は appendix へ分ける
- 文字の数値目安: 投影スライドの本文は 18pt 以上、タイトルと本文のサイズ比 (ジャンプ率) は 1.5〜2.5 倍、行間はフォントサイズの 1.5 倍前後。会場と媒体で調整してよいが、1 枚の中のサイズ段階は 3 つまでに抑える

## セルフチェック (出力前)

- [ ] 各スライドが 3 秒テスト (glance test) に合格する: 3 秒見て目をそらし、主張を言えるか。言えないスライドは要素を削るか分割する (Duarte)
- [ ] 全スライドのメッセージラインだけ読んで話が伝わる
- [ ] 結論が冒頭 3 枚以内にある
- [ ] 各グラフに「読み取ってほしいこと」の注釈がある
- [ ] 強調が 1 枚 1 箇所に収まっている
- [ ] 本編枚数が発表時間に収まり、詳細は appendix にある
