# Markdown Rules

- **Structure**: 1 H1 per file / heading level order (H1→H2→H3) / blank line before/after headings
- **Code blocks**: language required (` ```typescript `) / inline = backticks only
- **Links**: relative paths preferred / external = reference format preferred
- **Punctuation**: use `、。` (Japanese punctuation) / put a single half-width space before and after half-width alphanumeric runs when adjacent to Japanese characters (matches the majority style in `guidelines/writing/PRINCIPLES.md`; user 決定 2026-09-16)
